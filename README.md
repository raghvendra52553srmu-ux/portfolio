# Raghvendra Pandey — Developer Portfolio

Personal developer portfolio website for **Raghvendra Pandey**, BCA student at Shri Ramswaroop Memorial University (SRMU), Lucknow.

## 🚀 Built With
- **React 19**
- **Vite**
- **Tailwind CSS v4**
- **Framer Motion**
- **Lucide Icons**

## 💻 Projects Featured
- **MediKiosk:** AI-assisted clinical history-taking and OPD queue system for high-volume Indian hospitals.
- **Gurukul Digital Library:** Modern web platform for educational resources and learning materials.
- **Interview Saathi:** Web tool for interview preparation and spoken-English practice.
- **Python Quiz Game:** Interactive quiz project demonstrating logic and control flow.
- **Bunk Learn OS:** Academic attendance calculator and student task dashboard.

## 🛠️ Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/raghvendra52553srmu-ux/portfolio.git

# Navigate into the project directory
cd portfolio

# Install dependencies
npm install

# Run the development server
npm run dev
```
